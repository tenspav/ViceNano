3. 64MB STREAMING BUDGET & ASYNC PREFETCH DESIGN:
   - DRAM Budget (~40MB App Ceiling): Streaming Asset Pool = 18.0 MB (Textures 11.0 MB, DFF VBOs 7.0 MB); Static Core = 12.0 MB (Engine/Code 5.0 MB, Collision/IPL pools 3.0 MB, Audio/FB 4.0 MB); Ring Buffer = 4.0 MB; Margin = 6.0 MB.
   - Rolling Window: N = 2 to 3 zones (1 Current + 1-2 Lookahead along velocity vector). Opt C 3-zone window = 16.17 MB (fits in 18 MB pool). Opt B N = 2 zones (19.74 MB).
   - Async NAND Prefetch: Double-buffered DRAM ring buffer of 2x 2MB (4MB). At measured 30 MB/s NAND read, loading a full 5.4 MB zone takes 180 ms (11 frames @ 60fps).
   - Lookahead & Worst-Case Fit: P_lead = P + V * 2.5s (125m at 50 m/s top speed); prefetch triggers 2+ s ahead. Worst-case Downtown N+S (15.90 MB Opt C) fits inside 18.0 MB pool.
4. WORST SPOTS & MITIGATION STRATEGY:
   - Downtown Skyscraper Cluster (15.90 MB Opt C): Split Downtown N into East/West; clamp high-detail draw dist from 250m to 90m; enforce occlu.ipl box culling.
   - Little Haiti / Havana Density (13.34 MB Opt C): Deduplicate shared shack textures; downscale residential walls to 64x64; evict interior props outside 50m.
   - Bridges & Fast Crossings: Roosevelt Bridge (650m, 13s @ 50m/s) acts as streaming airlock; pin Island LODs (698 KB DFF) permanently; prefetch destination island at midpoint.
   - Memory Failsafe: Hard 18MB pool limit; evict non-visible peds/vehicles first (frees ~4MB); drop to 1/4-res texture mipmaps if NAND read queue latency exceeds 150ms.
